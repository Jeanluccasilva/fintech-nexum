# Nexum Fintech

Tela responsiva de dashboard financeiro desenvolvida para atividade acadêmica, utilizando HTML, CSS e Tailwind CSS.

## Como abrir

1. Extraia o projeto.
2. Abra o arquivo `index.html` em um navegador com acesso à internet.

O acesso à internet é necessário para carregar o Tailwind CSS e a fonte Inter pelas CDNs.

## Tecnologias

- HTML5
- CSS3 em arquivo separado
- Tailwind CSS via CDN
- Sem JavaScript próprio

## Publicação no GitHub

```bash
git init
git add .
git commit -m "feat: cria dashboard responsivo da fintech Nexum"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/fintech-nexum.git
git push -u origin main
```

Depois, substitua o texto de exemplo no arquivo `link-repositorio.txt` pelo link público real e gere o PDF que será enviado na atividade.
